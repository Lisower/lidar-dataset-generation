# lidar-simulator
- рандомизация траекторий и ракурсов сканирования
- ломанные траектории, линии Безье (тоже рандомизированные)
- фиксация FOV для траекторий
- сферический снимок территории с одной точки
- композитные снимки из множества таких сферических снимков из точки (например, как если бы производилось несколько замеров наземным или воздушным сканером из разных точек)
- автоподбор шага сканирования, чтобы при удалённой камере сканируемая местность содержала достаточное количество точек (но с возможностью задавать примерную частоту отсканированных точек в облаке точек)
- API для задания траектории, точек и ракурсов сканирования, шага и FOV сканера и частоту шумовых точек
- уменьшить частоту шума для траекторий (иначе слишком много шума получается)
- оптимизация сканирования по производитеьности и скорости загрузки ландшафтов в приложении
- улучшить проницаемость крон деревьев (а то под кронами вообще нет точек)
- шумовые точки:
	- значительно усилить амплитуду отклонения шумовых точек
	- добавлять шумовые точки между камерой и сканируемой поверхностью (симулируют рассеяние лучей по траектории от камеры до поверхности)
	- шумовые точки зеркального отражения (например, при отражении объектов в воде/стёклах)
# lidar-dataset-runner
- использовать генерацию территорий из terrains-generator
- для получения снимков территорий использовать lidar-simulator, и составлять из них датасет (на одну территорию может быть множество разных снимков - как одиночных, так и композитных с траекторий сканирования)
- выбор различных пресетов с весами для общего датасета
- статистика распределения пресетов и объектов генерации в созданном датасете
- разбиение выборки на тренировочную и проверочную
- улучшить UI и значок приложения
- главное - наладить полноценный пайплайн генерации датасета с заданными настройками с помощью одного приложения с папкой пресетов
