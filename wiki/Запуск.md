# Запуск на Linux

## Ubuntu / Debian

Нужен **Rust 1.97.1 или новее** (требование Bevy 0.20), графическая сессия и
драйвер видеокарты с поддержкой Vulkan. Первая сборка Bevy занимает много времени и места.

1. Установите инструменты и [зависимости Bevy для Linux](https://github.com/bevyengine/bevy/blob/main/docs/linux_dependencies.md):

   ```bash
   sudo apt update
   sudo apt install build-essential pkg-config curl libx11-dev libasound2-dev libudev-dev libxkbcommon-x11-0 libwayland-dev libxkbcommon-dev
   ```

   Для Intel/AMD при отсутствии Vulkan-драйвера: `sudo apt install mesa-vulkan-drivers`.
   Для NVIDIA используйте подходящий драйвер NVIDIA вашей системы.

2. Установите Rust через `rustup`, если он ещё не установлен:

   ```bash
   curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs -o /tmp/rustup-init.sh
   sh /tmp/rustup-init.sh -y
   source "$HOME/.cargo/env"
   ```

   Для существующей установки `rustup`: `rustup update stable`.
   Проверьте `cargo --version` и `rustc --version`: обе версии должны быть не ниже 1.97.1.
   Наличие `cargo` из системных пакетов само по себе не означает, что версия достаточно новая.

   Если после обновления по-прежнему используется старый Rust, в том же терминале
   выполните `source "$HOME/.cargo/env"` и `hash -r`, затем повторите проверку версий.

3. Запустите генератор из корня репозитория: шрифт ищется по абсолютному пути,
   поэтому рабочий каталог больше не важен:

   ```bash
   cd ~/Projects/lidar-dataset-generation
   cargo run --locked -p landscapes-generator
   ```

   Последующие запуски используют собранные зависимости. Для более быстрой генерации
   можно собрать с `--release`; первая такая сборка займёт дольше.
   При нехватке памяти добавьте `CARGO_BUILD_JOBS=2` перед `cargo run`.

## Ярлыки

Чтобы запускать приложения из меню, а не из терминала, создайте ярлыки:

```bash
cd ~/Projects/lidar-dataset-generation
cargo xtask launch-shortcuts --apps all          # все шесть приложений
cargo xtask launch-shortcuts --apps generators   # только Bevy-генераторы
```

На Linux `.desktop`-файлы появятся в `~/.local/share/applications` (`--desktop`
дополнительно кладёт копии на рабочий стол), на Windows — в меню «Пуск»
(`%APPDATA%\Microsoft\Windows\Start Menu\Programs\LiDAR`), на macOS — в
`~/Applications/LiDAR` в виде `.command`-скриптов.

Ярлык требует Rust и **собирает приложение при первом запуске** — первое окно
появится через несколько минут. Путь к `cargo` записывается в ярлык абсолютным,
поэтому его не нужно прописывать в `PATH` графической сессии. Список созданных
файлов хранится в `~/.local/share/lidar-dataset-generator/shortcuts.json` (на
Windows — `%APPDATA%\LiDAR`, на macOS — `~/Library/Application Support/LiDAR`).
Удалить всё созданное:

```bash
cargo xtask launch-shortcuts --remove
```

## Установка из пакета (раннер датасетов)

Установщики собираются в CI и лежат в артефактах прогона. Для Ubuntu/Debian:

```bash
sudo apt install ./lidar-dataset-runner_*.deb
```

После установки приложение запускается из меню приложений («LiDAR Dataset
Runner»); каталог пресетов лежит внутри пакета
(`/usr/lib/LiDAR Dataset Runner/presets`). Портативный вариант — `.AppImage`:
`chmod +x` и запуск файла; ярлык для AppImage ставит AppImageLauncher, сам файл
его не создаёт.

Установщик есть только у раннера: Bevy-генераторы без Rust не запустятся, для
них есть ярлыки выше.

## Управление

| Клавиша / мышь | Действие |
| --- | --- |
| `P` | Следующий пресет |
| `R` / `Shift+R` | Новый seed / повторить текущий |
| `V` | 3D-модель / облако точек |
| `Tab` | Орбитальная / свободная камера |
| ЛКМ + движение, колесо | Вращение, приближение в орбитальной камере |
| ПКМ + движение, `WASD`, `Q/E`, `Shift` | Обзор, полёт, вниз/вверх, ускорение |

## Проверка

Из корня репозитория:

```bash
cargo test --locked -p landscapes-generator
```

Другие генераторы запускаются аналогично: `cargo run -p buildings-generator`,
`cargo run -p plants-generator`, `cargo run -p terrains-generator` и
`cargo run -p lidar-simulator`. Запуск из каталога крейта тоже работает.
