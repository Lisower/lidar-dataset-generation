# Иерархия Entity создаваемых объектов
## Корень
Для каждого объекта создаётся корневой `Entity` с компонентом-маркером этого объекта.
Например, здание.
## Составные части
Для каждой составной части - свой `Entity`.
Например, для здания - это этажи, стены и крыша (как минимум).
Составные части могут иметь свои составные подчасти (например, этаж -> стена -> окно).
## Облака точек
Для каждой части, у которой есть смысл выделять своё облако точек, создаётся дочерняя сущность облака точек с соответствующим компонентом (то есть `Entity` части -> `Entity` облака точек). При этом класс точек может быть общим для компонентов (например, здания).
## Визуализация
Для каждой части и её облака точек отдельно навешиваются соответствующие компоненты для визуализации (меш и материал), если это полноценное приложение Bevy (т.е. окно с рендерингом).
## Transform и Occupancy
`Transform` нужен не только при визуализации, но и при headless генерации (т.е. без рендеринга), чтобы расставлять объекты на общей карте.
Также размещаемые объекты (здания, растения) имеют `Occupancy` (занимаемая территория), которая будет учитываться в `terrains-generator` (у него будет общий ресурс для этого).
