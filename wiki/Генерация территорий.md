# Генерация общих территорий

`terrains-generator` собирает территории размером 100×100 м: выбирает базовый ландшафт, здания и растения, размещает их с учётом воды, уклонов и занятости, показывает результат в Bevy и экспортирует облако точек без окна.

Геометрия всех объектов поступает из существующих `landscapes-generator`, `buildings-generator` и `plants-generator`. Улицы представлены свободными логическими коридорами; отдельные дорожные меши не создаются.

Для изменения кода см. [руководство разработчика](Разработка%20генератора%20территорий.md). История реализации и результаты предыдущей проверки — в [отчёте](Отчёт%20terrains-generator.md).

## Быстрый запуск

Нужны установленный Rust не ниже 1.97.1, Cargo и системные инструменты сборки. Для окна Bevy нужен работающий графический драйвер; `--headless` не создаёт окно и не требует GPU для вычисления сцены. Headless-режим использует те же зависимости сборки workspace. Linux-зависимости описаны в [инструкции запуска](Запуск.md).

Все команды ниже выполняются **из корня репозитория**, где лежит `Cargo.toml`. Пример для PowerShell — замените путь на каталог своей копии:

```powershell
cd "C:\Projects\lidar-dataset-generation"
cargo run -p terrains-generator -- conifer-forest 42
```

Первая сборка Bevy может занять заметное время. Последующие запуски используют собранные зависимости.

Чтобы посмотреть другую территорию, закройте окно и выполните одну из команд:

```sh
cargo run -p terrains-generator -- beach 42
cargo run -p terrains-generator -- residential-city 42
cargo run -p terrains-generator -- river 42
```

Справка и список доступных имён:

```sh
cargo run -p terrains-generator -- --help
cargo run -p terrains-generator -- --list
```

Синтаксис CLI:

```text
terrains-generator [preset] [seed] [--headless] [--output cloud.xyz]
```

| Аргумент | Поведение |
| --- | --- |
| `preset` | Встроенное имя или id файлового пресета; по умолчанию `field` |
| `seed` | Неотрицательное целое число `u64`; по умолчанию `42` |
| `--list` | Вывести встроенные имена и обнаруженные файловые id, затем завершиться |
| `--help` | Вывести краткую справку |
| `--headless` | Сгенерировать сцену без окна и вывести статистику |
| `--output путь.xyz` | Выгрузить XYZ; сам по себе также включает headless-режим |

Разделитель `--` после `cargo run -p terrains-generator` передаёт следующие аргументы программе. Для более быстрой генерации можно использовать `cargo run --release -p terrains-generator -- forest 42`; первая release-сборка выполняется отдельно.

## Управление и выбор пресетов

| Клавиша / мышь | Действие |
| --- | --- |
| `Ctrl+S` | Открыть или закрыть окно выбора пресетов |
| `V` | Переключить визуальные модели / облако точек |
| `R` | Получить новый seed и выбрать вариант из применённого набора пресетов |
| `Shift+R` | Повторить текущую конфигурацию с тем же seed |
| `Tab` | Переключить орбитальную / свободную камеру |
| ЛКМ + движение | Вращать орбитальную камеру |
| Колесо, `+` / `-` | Приближать и отдалять орбитальную камеру |
| ПКМ + движение | Поворачивать свободную камеру |
| `W`, `A`, `S`, `D` | Перемещаться в режиме свободной камеры |
| `Q` / `E` | Опускаться / подниматься в режиме свободной камеры |
| `Shift` | Ускорить движение свободной камеры |
| `Esc` | Закрыть окно выбора без применения изменений |

Чтобы постоянно перегенерировать один тип территории:

1. Откройте `Ctrl+S`.
2. Оставьте отмеченным только нужный пресет, например «Хвойный лес».
3. Нажмите **«Применить»**.
4. Используйте `R` для новых вариантов или `Shift+R` для повтора.

Если отмечено несколько пресетов, следующая сцена выбирается из них по seed. Открытие или сворачивание группы в списке само по себе не выбирает её содержимое. Закрытие через `Esc` или крестик отменяет неприменённые изменения. После изменения файлов пресетов перезапустите приложение, чтобы каталог был обнаружен заново.

Плашка слева сверху показывает название, seed, размеры карты, высоты, наличие воды, количество деревьев, кустов, пучков травы и зданий, название базового ландшафта, время генерации, режим вида и подсказки. При ошибке конфигурации в ней появляется сообщение; последняя корректно созданная сцена сохраняется.

| Группа | ID пресетов | Особенности |
| --- | --- | --- |
| Поля | `field`, `open-field` | Поле с целью 1–3 дерева либо без деревьев |
| Лиственный лес | `forest`, `forest-slope`, `forest-terraces` | Равнина, склон, террасы; кусты и густая трава |
| Хвойный лес | `conifer-forest`, `conifer-slope`, `conifer-terraces` | Обычная и высокая ели, сосны, кусты и можжевельник |
| Редколесье | `woodland`, `woodland-slope`, `woodland-terraces` | Реже расположенные деревья и большие открытые пространства |
| Склоны | `hill-slope`, `terraced-slope` | Деревьев нет; допустимы редкие кусты и трава |
| Водные территории | `river`, `pond`, `coast`, `sloping-river`, `waterfall` | Ивы ближе к воде, лиственные деревья дальше |
| Вода без деревьев | `river-open`, `pond-open`, `coast-open`, `waterfall-open` | Рельеф и вода сохраняются, деревья отключены |
| Морской пляж | `beach` | Береговой ландшафт, песчаный материал, оба вида пальм |
| Деревня | `village` | Смещённая основная улица и ответвление, разные частные дома |
| Частный сектор | `residential-city` | Регулярные коридоры улиц и смесь частных домов |
| Многоэтажная застройка | `town`, `apartment-city` | Многоквартирные здания существующего генератора |
| Небоскрёбы | `skyscraper-city` | Крупные высотные здания с увеличенными отступами |
| Избушка | `forest-cabin` | Домик и поляна среди леса |

Хвойные леса используют `Spruce`, `Fir`, `Pine`. Пляж использует `Palm` и `PalmCoconuts`. Для частного сектора и деревни доступны существующие `rectangular`, `l-shaped`, `annex`, `cabin`.

В каталоге пока один файловый пресет `apartment-block`: разновидности многоэтажек формируются его существующим генератором по seed. `town` и `apartment-city` сейчас используют одинаковые настройки композиции под разными id. Новые модели зданий в генераторе территорий не создаются.

## Экспорт XYZ

Генерация без окна:

```sh
cargo run -p terrains-generator -- river 42 --headless
```

Генерация и экспорт:

```sh
cargo run -p terrains-generator -- river 42 --headless --output assets/export/river.xyz
```

Путь результата отсчитывается от текущего каталога. Недостающие родительские папки создаются автоматически. Программа всегда пишет текстовый формат XYZ, поэтому используйте расширение `.xyz`.

Каждая строка имеет вид **`класс x y z`**, без заголовка:

```text
2 1.0 2.0 0.5
5 3.0 4.0 1.2
```

Координаты заданы в метрах; вертикаль данных — `Z`. Коды классов берутся из `generation-core::PointClass`: грунт — `2`, растительность — `5`, здания — `6`, вода — `9`.

Экспорт содержит облако **всей сгенерированной сцены**. Он не рассчитывает поле зрения сканера, перекрытия лучей, траекторию или измерительный шум. Это отдельная задача `lidar-simulator`; его текущая демонстрация сканирует здания. Сам `terrains-generator` не экспортирует LAS/LAZ или PLY.

## Как добавить свой пресет

### 1. Создать папку

Создайте `presets/terrains/nature/dry/my-field/`. Родительские папки `nature` и `dry` уже являются группами. В новую папку положите два файла: `manifest.ron` и `config.ron`.

### 2. Описать манифест

Содержимое `manifest.ron`:

```ron
(
    id: "my-field",
    name: "Моё открытое поле",
    description: "Равнина со средней плотностью травы, без деревьев и зданий",
    kind: "my-field",
)
```

`id` должен быть уникальным среди пресетов категории `terrains`. Рекомендуется использовать одинаковый технический идентификатор в `id`, `kind` и `config.name`. Русское отображаемое название хранится в `manifest.name`.

### 3. Задать состав сцены

Содержимое `config.ron`:

```ron
(
    name: "my-field",
    landscape_id: "plain",
    grass_id: "sparse-grass",
    grass_settings: (
        density: Medium,
    ),
)
```

Неуказанные счётчики деревьев, кустов и зданий равны нулю. Имя `my-field` не требуется добавлять в Rust enum: файловая конфигурация работает самостоятельно.

### 4. Проверить результат

Из корня репозитория:

```sh
cargo run -p terrains-generator -- --list
cargo run -p terrains-generator -- my-field 42 --headless
cargo run -p terrains-generator -- my-field 42
```

Новый пресет также появится в `Ctrl+S` после перезапуска программы.

### Пример смешанного леса

Для другого пресета создайте папку `presets/terrains/nature/dry/my-mixed-forest/`, задайте в манифесте уникальный id `my-mixed-forest` и используйте следующий **полный** `config.ron`:

```ron
(
    name: "my-mixed-forest",
    landscape_sources: [
        (id: "plain", weight: 2.0),
        (id: "slope", weight: 1.0),
    ],
    tree_sources: [
        (id: "deciduous-tree", weight: 3.0),
        (id: "high/coniferous", group: true, weight: 1.0),
    ],
    bush_sources: [(id: "bush"), (id: "juniper")],
    grass_sources: [(id: "sparse-grass"), (id: "tall-grass")],
    trees: 24,
    bushes: 8,
    grass_settings: (
        density: Dense,
        variants_per_preset: 4,
        min_scale: 0.8,
        max_scale: 1.2,
    ),
    placement: (
        tree_clearance: 1.0,
        plant_slope_deg: 35.0,
        cluster_probability: 0.78,
        cluster_radius: 17.0,
    ),
)
```

Здесь выбирается один ландшафт, а виды растений выбираются для каждого объекта. Лиственное дерево имеет вес `3`, вся группа хвойных — вес `1`. После раскрытия группы её вес делится между елью, высокой елью и сосной.

### Пересоздание встроенного каталога

```sh
cargo run -p terrains-generator --example dump_presets
```

Команда **перезаписывает** манифесты и конфиги 29 встроенных территорий по настройкам из `preset.rs`. Ручные изменения в этих файлах будут заменены. Пользовательские папки с другими id она не удаляет. Для собственного варианта используйте отдельную папку и уникальный id.

## Справочник конфигурации

Значения ниже — значения при чтении RON с пропущенными полями. Встроенные пресеты могут переопределять их, например задавать `Dense` вместо `Legacy`.

### Поля TerrainPresetData

| Поле | По умолчанию | Назначение |
| --- | --- | --- |
| `name` | Обязательное | Техническое имя конфигурации; непустая строка |
| `seed` | `Seed::default()` | Служебная метка; фактический seed задаётся CLI или аргументом API |
| `landscape_id` | `""` | Один пресет категории `landscapes` |
| `tree_id`, `bush_id`, `grass_id` | `""` | Один пресет соответствующего типа из `plants` |
| `building_id` | `""` | Один пресет категории `buildings` |
| `landscape_sources` | `[]` | Альтернативные базовые ландшафты |
| `tree_sources`, `bush_sources`, `grass_sources` | `[]` | Взвешенные источники растений соответствующего типа |
| `building_sources` | `[]` | Взвешенные источники зданий |
| `trees`, `bushes`, `grass`, `buildings` | `0` | Целевые счётчики с разбросом ±1/3; `grass` действует только при `Legacy` |
| `tree_count_range` | `None` | Точный диапазон цели деревьев, например `Some((1, 3))`; заменяет обычный расчёт цели `trees` |
| `max_slope_deg` | `10.0` | Максимальный уклон под зданием, от 0 включительно до 90 исключительно |
| `placement` | См. ниже | Правила распределения и застройки |
| `grass_settings` | См. ниже | Плотность и варианты травы |
| `sandy_ground` | `false` | Песчаный цвет материала грунта в viewer; форму рельефа и класс точек не меняет |
| `regenerate_landscape` | `true` | Пересоздавать известный архетип ландшафта с новым seed |

Нужен хотя бы один базовый ландшафт. Для ненулевого количества объектов нужны источники соответствующего типа. Ссылки проверяются и в отключённых категориях: оставшийся ошибочный `tree_id` не игнорируется только потому, что `trees: 0`.

### Элемент PresetSource

| Поле | По умолчанию | Правило |
| --- | --- | --- |
| `id` | Обязательное | Id пресета/группы либо относительный путь внутри категории |
| `group` | `false` | При `true` рекурсивно раскрыть группу |
| `weight` | `1.0` | Конечное положительное число |
| `min_water_distance` | `0.0` | Минимальное расстояние центра растения/пучка до воды, метры |
| `max_water_distance` | `None` | Верхний предел, например `Some(11.0)`; не меньше нижнего |

Ограничения расстояния используются для деревьев, кустов и травы. Для источников зданий и ландшафтов используются выбор и вес; водные ограничения этих источников в размещении не применяются.

### PlacementSettings

| Поле | По умолчанию | Назначение |
| --- | ---: | --- |
| `settlement` | `None` | `None` — свободное размещение; `Grid` — перекрёсток и кварталы; `Village` — основная улица с ответвлением; `Cabin` — дом вблизи центра |
| `street_width` | `6.0` | Положительная ширина городского коридора, м; деревня использует более узкие доли этой ширины |
| `setback` | `2.5` | Дополнительный отступ при размещении зданий, м |
| `tree_clearance` | `0.6` | Дополнительный зазор при размещении деревьев, м |
| `plant_slope_deg` | `35.0` | Предел уклона для деревьев и кустов; для травы используется минимум этого значения и 40° |
| `cluster_probability` | `0.78` | Вероятность искать место вокруг одного из кластеров; диапазон 0–1 |
| `cluster_radius` | `17.0` | Радиус распределения вокруг центра кластера, м |
| `clearing_radius` | `0.0` | Радиус свободной от растительности области вокруг центра карты, м |
| `waterfall_clearance` | `4.0` | Запас свободного пространства у водных занавесов и вниз по течению для деревьев и кустов; `0.0` отключает это правило |

Расстояния должны быть конечными и неотрицательными; уклоны — конечными числами в диапазоне `[0, 90)`.

### GrassSettings

| Поле | По умолчанию | Назначение |
| --- | --- | --- |
| `density` | `Legacy` | Выбор целевой густоты, см. таблицу ниже |
| `variants_per_preset` | `4` | Число вариантов геометрии каждого вида травы; от 1 до 32 |
| `min_scale` | `0.8` | Минимальный равномерный масштаб экземпляра; больше нуля |
| `max_scale` | `1.2` | Максимальный масштаб; не меньше `min_scale` |
| `min_water_distance` | `0.0` | Общий нижний предел расстояния травы до воды, м; действует вместе с пределами её источника |

| Плотность | Цель на территорию 100×100 м |
| --- | ---: |
| `None` | 0 пучков |
| `Sparse` | 800 |
| `Medium` | 3500 |
| `Dense` | 10000 |
| `Legacy` | Счётчик `grass` с разбросом ±1/3 |

`grass: 0` не отключает траву при `Medium` или `Dense`: для отключения задайте `grass_settings: (density: None)`.

## Группы, веса и правила выбора

Старые одиночные `*_id` продолжают работать. **Непустой** список `*_sources` полностью заменяет соответствующий одиночный id. При пустом списке используется одиночный id; при пустом id источников этой категории нет.

Ссылки разрешаются относительно своей категории: `high/coniferous` относится к `presets/plants/high/coniferous/`, а не к каталогу территорий. Можно использовать id манифеста `coniferous`. Для вложенного пути в RON применяйте `/`. Группа — папка с `is_group: true` в манифесте; каталог без манифеста также рассматривается существующим `PresetStore` как группа.

Порядок обработки:

1. Раскрыть группы вместе с вложенными группами.
2. Поделить вес группы поровну между её дочерними пресетами.
3. Устранить повторные ссылки на один пресет: первое упоминание задаёт его вес и ограничения.
4. Отсортировать кандидатов по id.
5. Выбирать кандидата по весу из потока случайности, определённого seed.

Разные файлы с одинаковым id считаются неоднозначной конфигурацией. Отсутствующие или пустые группы, несуществующие пресеты, повреждённые RON и несоответствие типа растения приводят к ошибке.

Вес определяет вероятность **выбора модели**, а не гарантированный процент в итоговой сцене. Часть объектов может не разместиться из-за воды, границ, уклона и занятости. При повторном появлении одного id через группу его вес не складывается с весом предыдущего упоминания.

Для базового ландшафта выбирается **один** кандидат; карты высот не накладываются друг на друга. При `regenerate_landscape: true` известный `kind` из каталога пересоздаётся через существующий архетип с текущим seed. Для сохранения своей формы из файлового `LandscapeConfig` задайте `false`. Неизвестный `kind` использует свой файловый конфиг. Размер карты всегда приводится к 100 м; при наличии зданий амплитуда шума ограничивается до 0,2 м.

## Правила размещения

Здания размещаются первыми; перед ними резервируются коридоры улиц. Затем размещаются деревья и кусты, в последнюю очередь — трава. Каждое место проверяется по границам карты, воде, уклону и занятости. При невозможности подобрать место объект пропускается. Заявленные счётчики — цели, поэтому фактическое количество может быть меньше, особенно для крупных домов и крутых рельефов.

Для поля `field` цель деревьев явно ограничена диапазоном 1–3. Для открытых полей, открытых водных вариантов и склонов без деревьев задан нулевой счётчик.

Растительность группируется в кластеры и оставляет открытые промежутки. Под кронами трава допустима; область основания ствола, здания, кусты, улицы и вода блокируют её. Основание каждого пучка устанавливается на точную интерполированную высоту рельефа. Это не деформация каждой травинки по поверхности склона.

Встроенные водные пресеты задают ивы не дальше 11 м от воды, лиственные деревья — не ближе 13 м, кусты — от 5 м, траву — от 2 м. Для пляжа пальмы размещаются от 7 м, трава — от 16 м. Эти пределы задаются в RON и могут быть изменены.

Расстояние до воды оценивается по сетке методом chamfer с восемью соседями. Если воды нет, оно считается бесконечным: верхнее ограничение, например для ив, не позволит разместить растение. Отдельная проверка попадания в воду исследует узлы под полным радиусом объекта с запасом в один шаг сетки.

## Каталоги данных

Поиск корня `presets/`:

1. Переменная окружения `LIDAR_PRESETS`.
2. Папка `presets/` рядом с исполняемым файлом.
3. Папка `presets/` в текущем каталоге.
4. Каталог `presets/` исходного workspace, заданный при сборке.

`LIDAR_PRESETS` указывает на общий корень с подкаталогами `terrains`, `plants`, `buildings`, `landscapes`, а не на одну категорию. Пример PowerShell:

```powershell
$env:LIDAR_PRESETS = "D:\LidarData\presets"
cargo run -p terrains-generator -- beach 42
Remove-Item Env:\LIDAR_PRESETS
```

При обычном запуске из исходников выбор сохраняется в `crates/terrains-generator/settings/preset-selection.ron`. При переносимом запуске настройки находятся рядом с корнем данных: `settings/terrains/preset-selection.ron`. Эти локальные настройки не коммитятся.

Шрифт ищется в `assets/fonts/Roboto-Regular.ttf`: каталог ассетов выбирается рядом с exe, в текущем каталоге либо в каталоге крейта. Для переносимой сборки положите `assets/` и полный `presets/` рядом с exe.

## Проверки и диагностика

```sh
cargo test -p terrains-generator
cargo check --workspace
cargo test --workspace --no-fail-fast -j 1
cargo fmt --all -- --check
cargo run -p terrains-generator --example profile_grass -- 10000
```

`profile_grass` сравнивает индивидуальную генерацию пучков с пулом вариантов, считает реальные меши, материалы и сущности ECS и измеряет густую лесную сцену. Он не измеряет FPS. Методика и устройство травы описаны в [руководстве разработчика](Разработка%20генератора%20территорий.md).

| Проблема | Что проверить |
| --- | --- |
| `could not find Cargo.toml` | Текущий каталог должен быть корнем репозитория или каталогом крейта |
| Пресет не появился в `Ctrl+S` | Перезапустить viewer; проверить выбранный корень данных, наличие `manifest.ron` и `config.ron`, уникальность id |
| «Выберите пресеты территории» | Открыть `Ctrl+S`, отметить хотя бы один пресет и применить выбор |
| «Пресет отсутствует или неоднозначен» | Проверить точный id, категорию, путь и повторяющиеся id; `--list` не проверяет содержимое всех конфигов |
| «Не относится к типу Tree/Bush/Grass» | В `tree_sources`, `bush_sources`, `grass_sources` должны попадать растения соответствующего типа |
| Травы нет или её меньше ожидаемого | Проверить `density`, водные ограничения, уклон, крупные пучки, застройку и пригодную площадь |
| При `R` меняется тип территории | В окне выбора отмечено несколько пресетов; оставить один и применить |
| Не находится шрифт после переноса exe | Проверить `assets/fonts/Roboto-Regular.ttf` рядом с программой |
| Конфликт имён `dump_presets` при общей сборке на Windows | Выполнить тесты последовательно с `-j 1` |

В последнем проверенном состоянии ветки тесты территорий проходят. В общем workspace остаются два ранее существовавших сбоя тестов размеров точек в `generation-core`, а общий `fmt --check` выявляет старое форматирование других модулей. Подробности и границы выполненной визуальной проверки зафиксированы в [отчёте](Отчёт%20terrains-generator.md).
