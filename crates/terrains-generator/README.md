# terrains-generator

Сборка процедурных территорий 100×100 м из готовых генераторов рельефа, зданий и растений. Крейту принадлежат конфигурация сцены и размещение объектов; геометрия поступает из `landscapes-generator`, `buildings-generator` и `plants-generator`.

## Быстрый запуск

Из корня репозитория:

```sh
cargo run -p terrains-generator -- conifer-forest 42
```

Другие примеры, каждый запускается отдельно:

```sh
cargo run -p terrains-generator -- beach 42
cargo run -p terrains-generator -- residential-city 42
cargo run -p terrains-generator -- river 42
cargo run -p terrains-generator -- --list
```

По умолчанию используются `field` и seed `42`. Первой сборке Bevy требуется время; для окна нужен работающий графический драйвер. Требования Rust и Linux-зависимости приведены в [README проекта](../../README.md) и [инструкции запуска](../../wiki/Запуск.md).

## Управление

| Клавиша / мышь | Действие |
| --- | --- |
| `Ctrl+S` | Выбрать пресеты; сохранить кнопкой «Применить» |
| `R` / `Shift+R` | Новый seed / повтор текущей генерации |
| `V` | Визуальные модели / облако точек |
| `Tab` | Орбитальная / свободная камера |
| ЛКМ + движение, колесо | Вращать и приближать орбитальную камеру |
| ПКМ + движение, `WASD`, `Q/E` | Обзор и перемещение свободной камеры |

Чтобы `R` менял только варианты одной территории, оставьте в `Ctrl+S` отмеченным один пресет и нажмите «Применить».

## Без окна и экспорт

```sh
cargo run -p terrains-generator -- river 42 --headless
cargo run -p terrains-generator -- river 42 --output assets/export/river.xyz
```

XYZ содержит строки `класс x y z`, координаты в метрах с вертикалью Z. Это облако всей сцены; сканирование лучами, окклюзия и измерительный шум в этой команде не рассчитываются.

## Настройки и разработка

29 поставляемых пресетов находятся в `presets/terrains/`. Поддерживаются пользовательские RON, списки источников, вложенные группы и веса. Для создания обычного нового варианта писать Rust-код не требуется.

- [Руководство пользователя и справочник RON](../../wiki/Генерация%20территорий.md).
- [Архитектура, API и правила разработки](../../wiki/Разработка%20генератора%20территорий.md).
- [Отчёт об изменениях и результатах проверок](../../wiki/Отчёт%20terrains-generator.md).

Проверки и CPU/ECS-бенчмарк:

```sh
cargo check -p terrains-generator --all-targets
cargo test -p terrains-generator
cargo run -p terrains-generator --example profile_grass -- 10000
```

`cargo run -p terrains-generator --example dump_presets` перезаписывает конфиги встроенного каталога. Для собственных вариантов создавайте отдельные папки с уникальными id.
