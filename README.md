# lidar-dataset-generator

## Сканирование здания

Пока генератор территорий не готов, `lidar-simulator` работает с отдельным
процедурным зданием. Запуск из корня проекта:

```sh
cargo run -p lidar-simulator
```

Исходное облако генерируется с шагом **0.08 м**, сканер независимо от него
отбирает точки с шагом **0.25 м**. Он проверяет поле зрения (90° × 70°),
дальность (0.1–150 м) и перекрытия стенами, крышей и деталями здания.
Для перекрытий используются двусторонние треугольники геометрии и дерево AABB,
поэтому промежутки между точками не пропускают лучи сквозь стены.

Шаг сканера — размер ячейки мировой пространственной сетки: из каждой ячейки
принимается ближайшая **видимая** точка. Это дискретизация готового облака,
а не модель углового развёртывания лучей конкретного прибора. Более плотное
исходное облако позволяет уменьшать шаг сканера без перегенерации здания.

По умолчанию в окне отображается всё исходное облако. Захваченные точки красные,
остальные серые (включая точки за пределами кадра, закрытые геометрией
и пропущенные при прореживании). Добавленные шумовые точки оранжевые.
Голубая пирамида показывает положение и направление сканера; линия — маршрут.
Клавиша **V** скрывает серый контекст и показывает только отсканированные
точки текущего кадра или накопленного результата (режим переключается **M**).
Повторное нажатие V возвращает полное облако, не меняя результаты измерений.
Камера наблюдения управляется независимо от сканера: после перемещения камеры
нажмите **Space**, чтобы переснять кадр с её позиции. Ракурсы ←/→ и траектория
T расположены выше крыши и направлены к центру здания; простой поворот камеры
наблюдения не перемещает голубую пирамиду сканера.

| Клавиши | Действие |
| --- | --- |
| ← / → | Одиночный кадр из предыдущего / следующего ракурса |
| Space | Одиночный кадр из текущего положения камеры наблюдения |
| T | Начать новый проход по круговой траектории (72 ракурса) |
| P | Приостановить / продолжить проход |
| M | Показать текущий кадр / накопленный результат |
| V | Всё облако с серым контекстом / только отсканированные точки |
| C | Сбросить накопление и снять один кадр с текущей позиции сканера |
| [ / ] | Уменьшить / увеличить шаг сканера и начать одиночный кадр |
| N | Выключить / включить шум (2%) и начать одиночный кадр |
| X | Сохранить отображаемый результат в PLY |
| R / Shift+R | Новое здание / повторить здание с тем же seed |
| Tab | Орбитальная / свободная камера |
| ЛКМ + движение / колесо | Орбитальное вращение / приближение |
| ПКМ + движение, WASD / QE, Shift | Обзор, движение и ускорение свободной камеры |

В накопленное облако попадает объединение всех отсчётов прохода. Повторное
наблюдение той же исходной точки не создаёт дубль; новые измерения шума
сохраняются отдельно. Шум **добавляется**, исходные отсчёты остаются на месте:
с вероятностью 2% на отсчёт создаётся дополнительная точка со смещением
до ±0.12 м по каждой оси. В данных используется существующий `PointClass::Noise`,
при экспорте — классификация **7 (Low Noise)**.

Для генерации итогового облака без окна:

```sh
cargo run -p lidar-simulator -- --headless --source-step 0.06 --scan-step 0.2 --noise-probability 0.02 --noise-extent 0.12 --frames 72 --seed 12648430 --output assets/export/building-scan.ply
```

Те же параметры доступны в оконном режиме без `--headless`. PLY содержит
только измеренные точки и их классы, без серого контекста. Координаты — метры,
вертикаль Y. Одинаковые seed и параметры дают одинаковый пакетный результат.
Файлы экспорта исключены из Git.

Библиотечный API: `ScanScene::new` принимает облако и треугольники любой сцены;
`ScanScene::from_building` учитывает иерархию и переводит Z-up здания в Y-up.
`scan` снимает кадр с `ScannerPose`, `ScanAccumulator` объединяет кадры одной
сцены, `orbit_trajectory` создаёт маршрут. Для собственного маршрута можно
передать последовательность поз в `scan`. При смене сцены нужен новый накопитель.

Проверки:

```sh
cargo test -p lidar-simulator
cargo check --workspace
```
